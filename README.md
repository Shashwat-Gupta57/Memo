## About

Four colours light up in a sequence; repeat it back. Every round adds one more step, until your memory gives out. A Simon-style game with a running score and a high score to beat.

## What it does

- **Growing sequences** — One more colour every round.
- **Score & high score** — Shown right in the centre.

## Download & run

1. These apps need **Java 21 or newer**. If you don't have it, install it once with the [JRE Installer](https://github.com/Shashwat-Gupta57/JRE-Installer/releases/latest) — one click, no admin rights. Every app looks for Java in the place it installs to first, then in `JAVA_HOME`.
2. Download **`Memo-1.0.0-windows.zip`** from the [latest release](https://github.com/Shashwat-Gupta57/Memo/releases/latest).
3. Unzip it anywhere you can write to (Desktop, Documents…) and run **`Memo.exe`**.

The folders next to the exe (images, fonts, saves) are part of the app — keep them together.

## Run from source

Open the folder in **BlueJ** (it's a BlueJ project — `package.bluej`) and run `main.main()`, or with any JDK 21+:

```bash
javac *.java
java main
```
